# EduGenie-AI

EduGenie-AI is an AI-powered educational learning assistant built using FastAPI and Google Gemini.

## Features

- Question & Answer
- Explain Concept
- Quiz Generator
- Text Summarization
- Learning Recommendations

## Technology Stack

- Python 3.11
- FastAPI
- Google Gemini
- HTML
- CSS
- JavaScript
- Jinja2
- Pydantic
- Pytest
