# Project Planning

## 1. Project Development Plan

The EduGenie project was planned as a sequence of development phases.

## Phase 1 - Brainstorming and Ideation

Activities:

- Identify the educational problem.
- Identify potential Generative AI applications.
- Define the target users.
- Select the major features.

## Phase 2 - Requirement Analysis

Activities:

- Define functional requirements.
- Define non-functional requirements.
- Identify required technologies.
- Define user interactions.

## Phase 3 - Project Design

Activities:

- Design the application architecture.
- Design the frontend interaction flow.
- Define API endpoints.
- Define AI integration.
- Plan modular Python components.

## Phase 4 - Project Planning

Activities:

- Select the technology stack.
- Plan backend development.
- Plan frontend development.
- Plan AI integration.
- Plan testing.
- Plan documentation and demonstration.

## Phase 5 - Project Development

Activities:

- Develop FastAPI backend.
- Develop frontend.
- Implement AI client.
- Implement Q&A.
- Implement concept explanation.
- Implement quiz generation.
- Implement summarization.
- Implement learning recommendations.

## Phase 6 - Project Testing

Activities:

- Test API endpoints.
- Run automated Pytest tests.
- Test frontend functionality.
- Test AI-generated outputs.
- Verify error handling.

## Phase 7 - Project Documentation

Activities:

- Prepare project documentation.
- Document architecture.
- Document requirements.
- Document installation and execution.
- Capture application screenshots.

## Phase 8 - Project Demonstration

Activities:

- Prepare demonstration flow.
- Demonstrate each major feature.
- Demonstrate API documentation.
- Demonstrate automated testing.
- Record the final project video.

## 2. Technology Stack

| Component | Technology |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, FastAPI |
| Server | Uvicorn |
| AI | Google Gemini |
| Testing | Pytest |
| Development Tool | Visual Studio Code |

## 3. Development Strategy

The project uses a modular development approach where individual
features are separated into different Python modules.

This makes it easier to test and maintain each feature independently.

## 4. Testing Strategy

Testing includes:

- Automated API testing
- Manual frontend testing
- AI functionality testing
- API documentation verification

## 5. Deployment/Submission Plan

The project source code and documentation are maintained in a public
GitHub repository.

The project demonstration is recorded and shared through a public
Google Drive link according to the project submission requirements.

## 6. Expected Deliverables

The planned deliverables are:

- Source code
- Requirements file
- Configuration example
- Testing files
- Project documentation
- Screenshots
- Public GitHub repository
- Project demonstration video
